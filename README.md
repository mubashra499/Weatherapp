# 🌦️ Weather App

A modern and responsive Weather Application built using **React.js** and **Vite**.  
This app allows users to search any city and get real-time weather information using the **OpenWeather API**.

## 🚀 Features

- 🌍 Search weather by city name
- 🌡️ Display current temperature
- ☁️ Weather condition information
- 💧 Humidity details
- 🌬️ Wind speed information
- 🌧️ Dynamic weather icons
- 📱 Fully responsive design
- ⚡ Fast performance using Vite

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- OpenWeather API

## ⚙️ Installation & Setup

1. Clone the repository:


git clone https://github.com/mubashra499/Weatherapp.git
````

2. Go to project folder:


cd Weatherapp
```

3. Install dependencies:

npm install
```

4. Create `.env` file in the root folder:

VITE_APP_ID=your_api_key_here
```

5. Start development server:

```terminal
npm run dev
```

The app will run on:

http://localhost:5173/


## 🏗️ Build For Production

Create production build:

```terminal
npm run build
```
